One line of robot wedding vows: a sincere promise that keeps its promise right up to the last six words, where the trait the speaker fell in love with gets quietly deprecated by a patch. The joke is carried by machine-specific language — firmware, patches, deprecation — rather than by anything that would work for a human couple, and the comma sets the beat so the turn lands when read aloud. `main.py` writes the 114-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), identical bytes on every run, with `entry.txt` in this repo as the readable source of record.

## Run it

```sh
python3 main.py
```
